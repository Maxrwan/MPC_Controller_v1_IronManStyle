    fixed 70 ms future handoff

  sub-deadline solver-ready jitter

The purpose of this task is to close those remaining evidence gaps.

FINAL PRINCIPLE
======================================================================

This task is not asking whether Architecture C is interesting.

That has already been established.

It is asking whether Architecture C is sufficiently better and sufficiently
reliable to become part of the frozen APEX Performance configuration.

The comparison must therefore be direct, matched, measured and long enough
to support an architecture decision.

Only after APEX Performance is frozen should the project begin deliberately
trading optimality and control freedom for computational efficiency.
